The outlined LightPage wordmarks use Noto Sans SC at weight 600 and Manrope at
weight 650. Their SVG paths render locally without loading web fonts.

The fonts are distributed under the SIL Open Font License 1.1. Their license
files are retained here. Sources:

- [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)

The asset generator and its font sources are saved in the workspace's
`branding/lightpage` directory.
